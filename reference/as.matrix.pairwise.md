# Converts a pairwise to a symmetric matrix. Uses the first entry for each (x,y) pair.

Converts a pairwise to a symmetric matrix. Uses the first entry for each
(x,y) pair.

## Usage

``` r
# S3 method for class 'pairwise'
as.matrix(x, ...)
```

## Arguments

- x:

  An object of class pairwise

- ...:

  other arguments

## Value

A symmetric matrix
